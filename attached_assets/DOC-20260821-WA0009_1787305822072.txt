BUG-C02 [CRITICAL] Fake authentication — zero backend integration
---------------------------------------------------------------
FILES:
  app/src/main/java/com/autopilot/driver/LoginActivity.kt
  app/src/main/java/com/autopilot/driver/SignupActivity.kt
  app/src/main/java/com/autopilot/driver/ForgotPasswordActivity.kt

LoginActivity.kt sets isLoggedIn=true with ANY email/password:

    AppPrefs.userEmail = email
    AppPrefs.authToken = "token_${System.currentTimeMillis()}"

Retrofit dependencies exist in build.gradle but are NEVER used.

FIX: Implement real API calls. Example for LoginActivity.kt:

    // 1. Create data classes
    data class LoginRequest(val email: String, val password: String)
    data class LoginResponse(val token: String, val email: String)

    // 2. Create API interface

        @POST("auth/login")
        suspend fun login(@Body req: LoginRequest): Response<LoginResponse>
    }

    // 3. In LoginActivity.kt onClick:

        val password = binding.etPassword.text.toString().trim()

BUG-C04 [CRITICAL] EncryptedSharedPreferences can crash on boot
-----------------------------------------------------------
FILE: app/src/main/java/com/autopilot/driver/BootReceiver.kt

BootReceiver calls AppPrefs.init(context.applicationContext) on boot.
On many Chinese OEM devices (Xiaomi, Oppo, Vivo), the Android Keystore is
broken or slow to initialize at boot time. EncryptedSharedPreferences.create()
can throw an exception, crashing the broadcast receiver silently.

BROKEN:
    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action == Intent.ACTION_BOOT_COMPLETED) {
            AppPrefs.init(context.applicationContext)  // CAN CRASH
            BotState.isRunning = false
            AppPrefs.isBotRunning = false
        }
    }

FIX:
    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action == Intent.ACTION_BOOT_COMPLETED) {
            try {
                AppPrefs.init(context.applicationContext)
            } catch (e: Exception) {
                // Keystore not ready; skip cleanup this boot
                Log.w("BootReceiver", "Keystore not ready", e)
                return
            }
            BotState.isRunning = false
            AppPrefs.isBotRunning = false
        }
    }

    // ALSO fix AppPrefs.init() itself with a fallback:
    fun init(context: Context) {
        prefs = try {
            val masterKey = MasterKey.Builder(context)
                .setKeyScheme(MasterKey.KeyScheme.AES256_GCM)
                .build()
            EncryptedSharedPreferences.create(
                context, NAME, masterKey,
                EncryptedSharedPreferences.PrefKeyEncryptionScheme.AES256_SIV,
                EncryptedSharedPreferences.PrefValueEncryptionScheme.AES256_GCM
            )
        } catch (e: Exception) {
            Log.w("AppPrefs", "EncryptedSharedPreferences failed, using fallback", e)
            context.getSharedPreferences(NAME + "_fb", Context.MODE_PRIVATE)
        }
    }

BUG-M07 [MEDIUM] traverse() obtains unnecessary copy of root
-------------------------------------------------------------
FILE: RideAccessibilityService.kt

traverse() calls AccessibilityNodeInfo.obtain(root) even though the
caller already has a valid root. Creates extra object overhead.

FIX: Remove obtain() in traverse:
    private fun traverse(root: AccessibilityNodeInfo, visitor: (AccessibilityNodeInfo) -> Unit) {
        val queue = ArrayDeque<AccessibilityNodeInfo>()
        queue.add(root)  // NOT: queue.add(AccessibilityNodeInfo.obtain(root))
        while (queue.isNotEmpty()) {
            val node = queue.removeFirst()
            try {
                visitor(node)
                for (i in 0 until node.childCount) {
                    node.getChild(i)?.let(queue::add)
                }
            } finally {
                node.recycle()
            }
        }
    }

    // Also remove root?.recycle() from onAccessibilityEvent's finally block
    // since traverse now owns the lifecycle.

BUG-M08 [MEDIUM] parseNumericValue() fragile for multiple dots
---------------------------------------------------------------
FILE: RideAccessibilityService.kt

"1.5.0" becomes "150" which might be a valid European format for "1.50".

FIX: Only apply dot-removal for Indian lakh patterns (7+ digits):
    private fun parseNumericValue(raw: String): Double? {
        val compact = raw.replace(",", "").replace(" ", "")
        return if (compact.count { it == '.' } > 1 && compact.length >= 7) {
            compact.replace(".", "").toDoubleOrNull()
        } else {
            compact.toDoubleOrNull()
        }
    }
