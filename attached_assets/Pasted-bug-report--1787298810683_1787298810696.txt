BUG-001 [CRITICAL] normalizeDigits() corrupts ALL non-digit characters
------------------------------------------------------------------------
The else branch converts every non-Indic-digit character to its Unicode 
codepoint number, then back to a Char. This turns '₹' into a random CJK 
character, destroys spaces, commas, and Latin letters. Price regex will 
NEVER match after normalization.

BROKEN CODE:
    else -> character.code

FIX:
    else -> character

CORRECTED METHOD:
    private fun String.normalizeDigits(): String = buildString(length) {
        for (character in this@normalizeDigits) {
            append(
                when (character) {
                    in '\\u0966'..'\\u096F' -> (character - '\\u0966' + '0'.code).toChar()
                    in '\\u0660'..'\\u0669' -> (character - '\\u0660' + '0'.code).toChar()
                    in '\\u06F0'..'\\u06F9' -> (character - '\\u06F0' + '0'.code).toChar()
                    else -> character
                }
            )
        }
    }

BUG-010 [MEDIUM] findAcceptButton picks first match, not best match
------------------------------------------------------------------------
If multiple clickable nodes match keywords, the first one is clicked. 
This could be a "Cancel" button that contains "Accept" in its description.

FIX: Score candidates and pick the best one:
    private fun findAcceptButton(root: AccessibilityNodeInfo): AccessibilityNodeInfo? {
        val candidates = mutableListOf<Pair<AccessibilityNodeInfo, Int>>()
        traverse(root) { node ->
            if (node.isClickable) {
                val text = node.nodeText()
                val score = acceptKeywords.sumOf { keyword ->
                    if (text.contains(keyword, ignoreCase = true)) keyword.length else 0
                }
                if (score > 0) candidates.add(AccessibilityNodeInfo.obtain(node) to score)
            }
        }
        return candidates.maxByOrNull { it.second }?.first
    }

BUG-012 [MEDIUM] Double-recycle risk in traverse() for caller's root
------------------------------------------------------------------------
The caller (onAccessibilityEvent) recycles root, and traverse() also 
obtains & recycles a copy. While obtain() creates a new reference, if 
rootInActiveWindow returns the same underlying node and the system 
recycles it internally, this can cause unpredictable behavior.

FIX: Don't obtain a copy in traverse; just use the passed root directly:
    private fun traverse(root: AccessibilityNodeInfo, visitor: (AccessibilityNodeInfo) -> Unit) {
        val queue = ArrayDeque<AccessibilityNodeInfo>()
        queue.add(root)  // Don't obtain here
        while (queue.isNotEmpty()) {
            val node = queue.removeFirst()
            try {
                visitor(node)
                for (i in 0 until node.childCount) {
                    node.getChild(i)?.let(queue::add)
                }
            } finally {
                node.recycle()
            }
        }
    }
    
    // Caller must NOT recycle root after calling traverse:
    // Remove root?.recycle() from onAccessibilityEvent's finally block
