# Autopilot - Ride Accepter

Auto-detects Accept buttons across all Indian languages and auto-clicks them based on price filter.

## Features
- Login / Signup / Forgot Password
- Admin panel for subscription management
- Auto-accept with Min/Max price filter
- 10 Indian language support for Accept buttons
- Onboarding with permission checks
- Start.io ads integration

## Build
```bash
./gradlew :app:assembleDebug
```

## Setup
1. Install APK
2. Complete onboarding (grant Accessibility + Overlay permissions)
3. Login or Signup
4. Set Min/Max price range
5. Tap START
6. Switch to your ride app
